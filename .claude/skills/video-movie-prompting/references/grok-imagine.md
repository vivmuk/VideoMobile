# xAI Grok Imagine

Use Grok Imagine for short cinematic prompts and, especially, image-to-video from an art-directed opening still. xAI's Video 1.5 workflow is: give a starting image, describe motion, then select supported duration and resolution. It can create sound effects, ambience, and dialogue with the video.

## Prompt shape

    [Framing and opening composition.] [Subject] in [specific environment].
    [Chronological physical action and environmental response.]
    Camera starts [position], then [one move and pace], ending [position].
    [Lighting, materials, palette, visual treatment.]
    Sound: [ambience, effects, and/or one brief line].

Use the source still for identity/composition. Prompt motion, camera, sound, and the end state rather than re-describing the still. Revise only the needed timing, color, or camera path.

Use reference-to-video or extension only when that exact live model supports it. Retain approved source clips and generated outputs in the film ledger.

Sources: [Grok Imagine Video 1.5](https://x.ai/news/grok-imagine-video-1-5), [xAI video-generation use case](https://x.ai/grok/use-cases/video-generation), [Imagine API](https://x.ai/api/imagine).
