# ByteDance Seedance

Use Seedance for complex movement, reference-rich direction, designed sound, and compact multishot sequences. ByteDance documents text/image/audio/video mixed inputs and direction of composition, camera movement, visual effects, audio, and 15-second multishot audio-video output.

## Prompt shape

    References: image 1 = [character], image 2 = [wardrobe/prop], image 3 = [location],
    video 1 = [motion rhythm], audio 1 = [sound palette].
    [Opening shot/framing.] [Subject] performs [first physical event].
    The camera [move/cut], revealing [next event and consequence].
    Lighting/style: [concise visual direction].
    Audio: [dialogue, ambience, music, foley, intentional silence].

Give every asset a role. Write physical events, cuts, speed changes, and sound in order. Use a multishot request for a few deliberate beats, not an entire act. Review multi-subject consistency, text, complex effects, and audio for each take.
